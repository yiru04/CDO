Methodology
Step 1 — Loss Given Default per Company
LGD = (1/n) × (1 − RR)
= 10% × (1 − 40%) = 6% of portfolio notional

n=10 companies（等權重），RR=40%（固定假設）
Step 2 — Convolution Algorithm

BB（6.52%）和 B（16.93%）的 PD 不同，不能用二項分佈（二項分佈要求每次試驗概率相同）。逐步卷積：

f[0]=1, f[k]=0 for k>0 ← 初始：0家違約=100%
For i = 1 to n:
f[k] = f[k]×(1−pᵢ) ← 第i家沒違約
+ f[k−1]×pᵢ ← 第i家違約

→ 解析精確解，無任何抽樣誤差
Step 3 — Tranche Metrics
P(hit) = Σ f[k] for k×LGD > attach
P(wipe) = Σ f[k] for k×LGD > detach

EL = Σ f[k] × max(min(k×LGD, detach) − attach, 0)

EL/Width = EL ÷ (detach − attach)　← tranche 定價依據

Theory — Gaussian Copula & CDO Pricing

核心問題：為什麼需要 Copula？

我們知道每家公司各自的 PD（BB=6.52%，B=16.93%），但 CDO 的損失取決於「多家同時違約」。要計算聯合概率，需要一個聯合分佈。

問題：違約是 0/1 事件，不能直接用雙變數常態。而且：如果把相關性和 PD 混在一起，調整一個就會破壞另一個。

Copula 的解法：把兩件事分開——個別 PD 不動，只在上面加一層相關性。Sklar's Theorem（1959）保證這樣的分拆是合法且唯一的：

H(x,y) = C( Fx(x), Fy(y) )

H = 聯合分佈
Fx, Fy = 各公司個別的邊際分佈
C = Copula（只描述相關性）

Gaussian Copula — 三步驟

Step 1：τᵢ → uᵢ = Fτ(τᵢ) ∈ [0,1] 任何分佈 → 均勻分佈
Step 2：uᵢ → xᵢ = Φ⁻¹(uᵢ) ~ N(0,1) 均勻 → 常態
Step 3：(x₁,...,xₙ) ~ N(0,Σ) 放入相關矩陣

C^Ga_ρ(u,v) = Φ_ρ[ Φ⁻¹(u), Φ⁻¹(v) ]

關鍵：u 和 v 可以來自任何邊際分佈，同一個 Φ_ρ 機器把相關性黏上去。

One-Factor Gaussian Copula — 視覺化

每家公司的命運 = 市場因子 M（共享）+ 特異衝擊 Zᵢ（獨立）

ρ 如何改變損失分佈 — 示意圖

ρ 小（獨立）→ 鐘形，中間集中

ρ 大（高度相關）→ 兩端集中，fat tail

!

本組合（高 PD）的反直覺結果： ρ 上升讓「剛好 k=2」的中間情境減少，Senior 反而更安全。這和低 PD 的 IG 組合（ρ 上升讓 Senior 更危險）行為相反，說明 Copula 的影響方向取決於組合的 PD 水準。

Implied Correlation — Correlation Smile

市場上不同 tranche 的 spread 反推出的 implied ρ 不一樣——Equity 的 implied ρ 和 Senior 的不同。這叫 correlation smile，說明單一 ρ 值無法描述整個 CDO 的市場定價，是 Gaussian Copula 的根本限制。

Correlation Delta — ρ 對各 Tranche 的影響方向

Equity spread 對 ρ 呈負相關，Senior 呈正相關（IG 組合）。兩者方向相反，是 Correlation Trading 的基礎。

Correlation Trading

  • Long Correlation：買 Equity 保護 + 賣 Senior 保護。押注 ρ 上升（危機）。2008 年獲利。
  • Short Correlation：賣 Equity 保護 + 買 Senior 保護。押注市場平靜，收取高額 Equity spread。2006–2007 年盛行，2008 年 ρ 急升全部爆倉。
