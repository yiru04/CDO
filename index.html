Methodology
Step 1 — Loss Given Default per Company
LGD = (1/n) × (1 − RR)
= 10% × (1 − 40%) = 6% of portfolio notional

n=10 companies（等權重），RR=40%（固定假設）
Step 2 — Convolution Algorithm

BB（6.52%）和 B（16.93%）的 PD 不同，不能用二項分佈（二項分佈要求每次試驗概率相同）。逐步卷積：

f[0]=1, f[k]=0 for k>0 ← 初始：0家違約=100%
For i = 1 to n:
f[k] = f[k]×(1−pᵢ) ← 第i家沒違約
+ f[k−1]×pᵢ ← 第i家違約

→ 解析精確解，無任何抽樣誤差
Step 3 — Tranche Metrics
P(hit) = Σ f[k] for k×LGD > attach
P(wipe) = Σ f[k] for k×LGD > detach

EL = Σ f[k] × max(min(k×LGD, detach) − attach, 0)

EL/Width = EL ÷ (detach − attach)　← tranche 定價依據

Theory — Gaussian Copula & CDO Pricing

什麼是 Copula？— Sklar's Theorem

Copula 是把多個邊際分佈連結成聯合分佈的函數：

F(x₁,...,xₙ) = C(F₁(x₁),...,Fₙ(xₙ))

C = Copula 函數
Fᵢ = 公司 i 的違約時間邊際分佈（由 PD 決定）

關鍵靈活性：可以在不改變任何公司個別 PD 的情況下，單獨調整公司之間的相關性結構。

Gaussian Copula — 三步驟

1. τᵢ → uᵢ = F_τ(τᵢ) ∈ [0,1] uniform 化
2. uᵢ → xᵢ = Φ⁻¹(uᵢ) ~ N(0,1) 常態化
3. (x₁,...,xₙ) ~ N(0, Σ) 放入相關矩陣

C = Φₙ(Φ⁻¹(u₁),...,Φ⁻¹(uₙ); Σ)

One-Factor Gaussian Copula — CDO 定價標準模型

為避免估計 n×n 相關矩陣，簡化為一個市場系統性因子 M：

xᵢ = √ρ·M + √(1−ρ)·Zᵢ

M ~ N(0,1)：所有公司共享的市場因子
Zᵢ ~ N(0,1)：公司 i 的特異因子（相互獨立）

公司 i 違約 ⟺ xᵢ < Φ⁻¹(PDᵢ)

P(公司 i 違約 | M) = Φ([Φ⁻¹(PDᵢ) − √ρ·M] / √(1−ρ))

給定 M，各公司條件獨立。ρ=0 時 M 消失，退化為本作業的卷積法（可作為 MC 驗證）。

ρ 如何影響損失分佈與各 Tranche？

  • ρ → 0：損失集中中間值（少數獨立違約）
  • ρ → 1：損失集中兩端（要麼全無事，要麼系統性崩潰）

對 Senior 的影響取決於組合 PD 水準：
低 PD 組合（IG）：ρ 上升 → Senior 變危險（極端崩潰情境概率上升）
高 PD 組合（HY）：ρ 上升 → Senior 反而受益（「剛好足夠觸發 Senior」的中間情境減少）
本作業為 BB+B 高 PD 組合，屬於後者，實驗可在 Copula 頁驗證。

Equity spread 對 ρ 呈負相關（ρ升 → Equity spread 降）；Senior spread 的方向則視 PD 水準而定。

Implied Correlation — Correlation Smile

市場上不同 tranche 的 spread 反推出的 implied ρ 不一樣，形成 correlation smile（或 skew），說明單一 ρ 值無法完整描述市場，是 Gaussian Copula 的根本限制之一。

2008 年金融危機 — Copula 的失敗

  • ρ 被低估：歷史估計 ρ≈0.3，危機時實際飆升至 0.7–0.9，所有資產同步崩潰
  • Gaussian 尾端太薄：常態分佈低估了系統性崩潰的頻率（fat tail 被忽視）
  • Correlation smile 被忽視：市場 implied ρ 不是常數，模型假設它是
  • 模型被誤用：定價工具被當作風險管理工具，Senior tranche 被大量評為 AAA

本作業用 ρ=0 算出的 Senior PD 是最樂觀估計（下限）。現實中 ρ>0，Senior 實際風險更高，在 Copula 頁可驗證。

Nth-to-Default Swap 與 CDO 的數學等價

CDO tranche 和 Nth-to-Default basket swap 共用同一個損失分佈：

  • P(≥1 家違約) = First-to-Default 觸發概率 = Convolution 頁 P(≥k) 表第 1 行
  • P(≥2 家違約) = Second-to-Default 觸發概率 = Senior tranche 的 P(any loss)

反直覺：ρ 上升讓 FtD spread 下降（「只有一家違約」中間情境減少）——和 Senior tranche 方向相反，是 Copula 最直觀的反直覺結論。

Correlation Trading

  • Long Correlation（買 Equity 保護 + 賣 Senior 保護）：押注 ρ 上升（危機）。Senior spread 上升使賣出的保護虧損，但 Equity spread 下降使買入的保護獲利，整體受益。
  • Short Correlation（賣 Equity 保護 + 買 Senior 保護）：押注市場平靜。平靜時 Equity spread 高，賣出收入豐厚；Senior spread 低，買入成本低。2006–2007 年大行其道，2008 年 ρ 急升，全部爆倉。
